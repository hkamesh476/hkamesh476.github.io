Why Rust

Rust is a programming language that runs as fast as C and C++, but checks your code for whole families of memory bugs before the program ever runs. That's why it shows up in places where speed and reliability both matter, from web browsers to operating systems.

I want to understand how a language can be fast and safe at the same time. I also like how the Rust compiler works: when something is wrong, it explains exactly what and often suggests the fix, which feels a lot like having a good teacher.

What I'm learning

  • Ownership

    Every value in Rust has exactly one owner. When the owner goes out of scope, the value is cleaned up automatically, with no garbage collector running in the background.

  • Borrowing

    Instead of handing a value over, you can lend it with a reference. You can have many read-only references or one mutable reference at a time, never both, and the compiler checks this for you.

  • Option and Result

    Rust has no null. A value that might be missing is an Option, and an operation that might fail returns a Result, so you have to deal with both cases on purpose.

  • Pattern matching

    The match keyword checks a value against every possible shape it could take, and the compiler complains if you forget one.

  • Cargo

    Rust's build tool and package manager. One command creates a project, another builds and runs it.
